# ntqr.notebooks

Tutorial notebooks packaged with `ntqr`. Start with `Tutorial.ipynb`, then
`LogicOfUnsupervisedEvaluationTutorial.ipynb`.

| Notebook | Topic |
|----------|-------|
| `Tutorial.ipynb` | Getting started |
| `LogicOfUnsupervisedEvaluationTutorial.ipynb` | Logic of label-free evaluation |
| `AlgebraAndGeometryOfNTQR.ipynb` | Algebra and geometry of NTQR |
| `ExactAlgebraicSolutionErrorIndependent.ipynb` | Exact error-independent solutions |
| `HowManyIndependentAxioms.ipynb` | How many independent axioms exist |
| `LogicalAlarmsMisalignedClassifiers.ipynb` | Detecting misaligned classifiers |
| `PossibleAndConsistentSet.ipynb` | Possible and consistent evaluation sets |

These ship inside the installed package. Clear cell outputs before committing.
