# multi_llm_personas_evaluation/

Results of `scripts/llm/multi_llm_personas_evaluation.py`: the same persona trio run through six local Ollama models. Top level holds aggregate `summary.json`, figures (`*.png` + `*.data.json`), `cache.json` (raw Ollama response cache), and temperature/baseline comparison JSONs. Per-model vote and evaluation files live in `models/<model>/`.
